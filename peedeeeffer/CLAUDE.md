# PeeDeeEffer, `/peedeeeffer`

In-browser PDF split, merge, extract and EPUB tool with a heavy-file mode.

- `index.html` is current; `indexstable*.html`, `oldindex.html`, `merge.html` are older copies. pdf.js, JSZip, SortableJS from CDN. Nothing uploaded.

Static, no build step; deploys on push to `main`. Follow the root `CLAUDE.md` (and `AESTHETIC.md` for anything new).

# Talkonomics weekly quiz, `/quiz`

The Talkonomics weekly economics quiz: latest edition plus archive.

- `index.html`, `feed.json`, `posts/` (HTML + PDF per edition), `oldquizzes/`, banner images.
- Generated by `quiz_scripts/quiz_generate.py`; generation prompt in `talkonomics-generation-prompt.md`.

Static, no build step; deploys on push to `main`. Follow the root `CLAUDE.md` (and `AESTHETIC.md` for anything new).

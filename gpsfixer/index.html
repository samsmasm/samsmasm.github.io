GPS Fixer

Redraw the bit where your GPS gave up. Your file never leaves this browser.
unisam.nz

1Open a GPX file

Choose a .gpx file or drop it here

2Choose the gap

Long jumps between recorded points are listed below. They are only suspects: some straight sections are real.

3Draw the real route

  • Click the map to add points, in order, from A towards B.
  • Drag an orange point to move it. Click one to remove it.
  • Drag a hollow midpoint to bend a line.
–

4Calculate timestamps

Spreads the time between A and B along your route by distance, so the section is covered at a constant average speed. These are estimates, not recovered GPS data.

5Review and download

Recorded track Original gap (being replaced) Your repair (estimated)

Upload the downloaded file to Strava as a new activity (delete the old one first if you want to replace it). Strava works out its own distance from the track, so it may differ a little from the figure here.

Privacy: your GPX file is read, edited and saved entirely in this browser. Nothing is uploaded. The only network requests are for map tiles (OpenStreetMap data, served by CARTO), which reveal roughly which area you are looking at, as any web map does.

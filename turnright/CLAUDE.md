# turnright, `/turnright`

Generates walking routes by always turning one way (left- or right-hand rule) from a start pin for a target distance, on OSM streets.

- Single `index.html`. Leaflet + Overpass API. Related to `longcut/` (see its CLAUDE.md for the OSM graph gotchas).

Static, no build step; deploys on push to `main`. Follow the root `CLAUDE.md` (and `AESTHETIC.md` for anything new).

# mymaths, `/mymaths`

Sam's personal roadmap from NCEA Level 3 to graduate-level mathematics.

- This folder is a **static Next.js export** (`_next/`, `__next.*.txt`). The source is not in this repo; do not hand-edit the built files beyond small fixes.
- `study_plan.md` is the plan text; `modules.json` / `modules/` hold the module data; `add_lo_detail.py` adds learning-outcome detail.

Static, no build step; deploys on push to `main`. Follow the root `CLAUDE.md` (and `AESTHETIC.md` for anything new).

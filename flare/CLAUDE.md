# Classroom Flare, `/flare`

Students press a button to signal the teacher (e.g. 'I'm lost'); when enough do, the teacher's screen plays a sound.

- `index.html`, `script.js`, `styles.css`, sound files. Firebase project `dowserboard` (shared with Dowser, Pulse-era tools).
- Teacher sets threshold, cooldown and button text.

Static, no build step; deploys on push to `main`. Follow the root `CLAUDE.md` (and `AESTHETIC.md` for anything new).

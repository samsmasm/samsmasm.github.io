# Wingeometer, `/wingeometer`

NZ parliamentary speech analyser: language patterns by party from Hansard (future/past, positive/negative, fear, we/they).

- `index.html`, `data.js` (precomputed stats). Source analysis lives in `~/wingedicator/`.

Static, no build step; deploys on push to `main`. Follow the root `CLAUDE.md` (and `AESTHETIC.md` for anything new).

# Tile Reveal, `/reveal`

Upload an image, cover it in tiles, click to reveal it bit by bit (classroom guessing game).

- `index.html` (React + Babel standalone + Tailwind from CDN), `index2.html` (alt), preset images `1.png`..`5.png`.

Static, no build step; deploys on push to `main`. Follow the root `CLAUDE.md` (and `AESTHETIC.md` for anything new).

# Operation: Shadow Protocol, `/coldwar`

Cold War classroom role-play game: nations, team goals, individual missions, live scoreboard.

- Single large `index.html`. Firebase Realtime Database in `coldwar-d8109` (the same project Checkin, aiorus and Lineup use for Firestore).
- Separate local copy may exist at `~/coldwar/`; check which is current before editing.

Static, no build step; deploys on push to `main`. Follow the root `CLAUDE.md` (and `AESTHETIC.md` for anything new).

# unisam photos, `/photos`

Sam's photo gallery with tags.

- `index.html`, `manifest.json`, `store/`. Firebase project `unisam-photos` for metadata and admin.
- Add photos, run `node generate-manifest.js` (repo root), commit images + manifest. See `SETUP.md`.

Static, no build step; deploys on push to `main`. Follow the root `CLAUDE.md` (and `AESTHETIC.md` for anything new).

# CLAUDE.md — EconNews

## What this is

**EconNews** is a weekly economics news feed for IB Economics students. Articles are curated and published to a static GitHub Pages site. Students see articles grouped by date; the most recent week is at the top.

Live at: `unisam.nz/econnews/`

---

## File structure

```
econnews/
  index.html          ← reader frontend (loads posts.json, renders article list)
  archives.html       ← archive browser
  style.css           ← all styles
  feed.json           ← raw feed data (for pipeline use)
  posts.json          ← published article data consumed by index.html
  posts/
    YYYY-MM-DD.html   ← one HTML file per publication date
```

---

## Data format: posts.json

`posts.json` is a flat array of weekly post objects consumed by `index.html`:
```json
[
  {
    "date": "2026-06-07",
    "articles": [
      {
        "title": "...",
        "url": "...",
        "source": "The Guardian",
        "summary": "...",
        "tags": ["demand", "inflation"]
      }
    ]
  }
]
```
Sorted newest-first. `index.html` reads this via `fetch('posts.json')`.

## Posts folder

Each `posts/YYYY-MM-DD.html` is a standalone article digest page for that week, linked from the main feed. HTML fragment, not a full document (index.html wraps it).

## Pipeline

Articles are generated by scripts in `econnews_scripts/` (not in this directory). The pipeline:
1. Fetches RSS feeds from economics news sources
2. Scores articles for IB Economics relevance via Claude
3. Selects and summarises the best articles
4. Writes a new entry to `posts.json` and creates `posts/YYYY-MM-DD.html`
5. Commits and pushes (deployed via GitHub Actions)

---

## Key constraints

- `index.html` fetches `posts.json` on load — no server-side rendering.
- Do not hardcode articles in `index.html`; they must come from `posts.json`.
- The `feed.json` file is pipeline-internal; `posts.json` is what the frontend reads.
- The archives page (`archives.html`) lists all `posts/YYYY-MM-DD.html` files.
